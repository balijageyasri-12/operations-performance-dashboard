# Operational Performance Analytics Dashboard 📊

## 📌 Project Overview
This project transforms raw operational performance data into structured, actionable business insights. Using **SQL**, I developed data cleaning and aggregation scripts to process customer interaction records, tracking operational key performance indicators (KPIs) like **Turnaround Time (TAT)**, **Customer Satisfaction (CSAT)**, and **First Contact Resolution (FCR)**. This mimics data architecture structures utilized in large-scale operations tracking centers like Infinix.

## 🛠️ Tools & Technologies Used
* **Database Querying:** SQL (Aggregate functions, Case Statements, Data Mutability)
* **Data Visualization Prep:** Power BI / Tableau metrics planning
* **Process Focus:** Turnaround Time optimization, SLA tracking

## 📂 Project Deliverables
* 💻 **[dashboard_queries.sql](./dashboard_queries.sql):** Production-ready SQL script detailing table updates, data filters, metrics extraction, and performance indexing.
* 📄 **[operations_dashboard.txt](./operations_dashboard.txt):** Conceptual framework outlining metrics mapping, structural data layout, and performance targets.

## 🎯 Business Analytics Impact
* **Actionable Performance Metrics:** Structured SQL logic to calculate precise agent processing times, highlighting workflow bottlenecks.
* **Data-Driven Evaluation:** Modeled customer satisfaction weighting algorithms to enable objective, performance-based team resource routing.
